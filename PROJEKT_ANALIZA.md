NewLux Event Centar je kompletan web sajt za event centar specijalizovan za:

- 👶 Krštenja

## 🛠️ Tehničke Specifikacije

### Frontend Stack:
- **HTML5** - Semantički strukturiran markup
- **CSS3** - Moderne stil stilizacije sa custom properties
- **JavaScript (Vanilla)** - Dinamički funkcionalitet
- **Bootstrap 5.3.0** - Responsive layout i komponente
- **Swiper.js 9** - Napredni slajderi i karuseli
- **jQuery 1.11.0** - DOM manipulacija (legacy)
- **AOS (Animate On Scroll)** - Scroll animacije

### Fontovi:
- **Dancing Script** - Elegantni naslovni font
- **Lato** - Čitljiv body font

### Ikone:
- **Iconify** - Modern SVG ikone
- **Custom SVG sprite** - Inline ikone

### Template Base:
- **TemplatesJungle "Beauty" Template**
- Prilagođeno za event centar
